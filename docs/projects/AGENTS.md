# `docs/projects/`

A project doc is a design doc for in-flight or pending work: it names the higher intent, sketches the desired end state, and records the approach. Load one into context only when the user names it or asks to work on that initiative.

A project doc has a lifecycle: when the work ships, its lasting content folds into a reference or rules doc, and the project doc is deleted.

Skim the filenames and title lines first.
